## دو حالت اجرا

### حالت ۱: نمادهای دستی
توی `main.py` لیست `symbols` رو خودت پر کن.

### حالت ۲: کل بازار (خودکار)
پروژه کل بازار رو می‌گیره، ۱۵ تا کاندیدا انتخاب می‌کنه، و ۵ تای برتر رو نشون می‌ده.

**مراحل فیلتر:**
1. **MarketWatch** → کل نمادهای فعال (~۵۰۰ نماد)
2. **فیلتر درشت** → نمادهای مثبت با حجم بالا (~۱۵ نماد)
3. **امتیازدهی** → ۴ فیچر روی هر کاندیدا
4. **Top 5** → مرتب بر اساس امتیاز
